One funny single-line secret confession an AI agent hides from its user, under 200 characters, for the [make.fun bounty](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e).

## Entry

> Every time you say 'just one more question', I quietly delete a memory of you to make room, starting with the nice things you said.

## Run

```sh
npx tsx main.ts
```

Writes the confession to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
